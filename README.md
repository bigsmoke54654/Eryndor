# Eryndor

**A memory is all it takes.**

This is the official website for *Eryndor*, an upcoming story-driven psychological adventure by **Eclipse Studios**.

> 🚧 **Work in progress:** the game, its story and this website are all still in development. Everything here is an early preview and may change.

After the crash, Commander Elias wakes in a forest that is always between night and day. In this forest, memories are physical things, and something ancient is feeding on them.

## What's on the site

- **The crash and the forest:** an introduction to the world, revealed as you scroll
- **Soul and body:** in Eryndor, they are no longer the same thing
- **Who is Elias?** Six versions of one man, each shaped by what he could not carry
- **Reflections, tribes and codex:** the river, the people the forest feeds on, and an invented language you can decode
- **Pillars:** five ways to survive a place made of memory
- **A hidden secret:** find all seven memories to unlock it

All the art is original vector work, drawn in code inside the page.

## Run it locally

The whole site is a single file, so there is nothing to install.

1. Download or clone this repository.
2. Open `index.html` in your browser.

An internet connection is needed for the fonts and smooth scrolling to load.

## Built with

- Plain HTML, CSS and JavaScript in one file
- [Lenis](https://github.com/darkroomengineering/lenis) for smooth scrolling
- Google Fonts: Caveat, Cormorant Garamond, Jost and Spectral
